# Pseudonymous event evidence citations

[[AIDEV-39]] adds stable citation infrastructure for hindsight documents. Event citations must be attached after redaction, use pseudonymous ordinal references instead of raw session/entry IDs, and point to inspectable source context. Generated-document claims must require available evidence, explicitly classify as `direct evidence` or `inference`, reject unknown classifications and unavailable citations, and use generated ordinal anchors rather than lossy reference sanitization.
