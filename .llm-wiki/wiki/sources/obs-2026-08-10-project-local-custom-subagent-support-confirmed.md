# 🔍 Observation: Project-local custom subagent support confirmed

pi-sampler can define project-local pi-subagents agents in `.pi/agents/**/*.md`; project definitions override user and bundled agents. The installed pi-subagents documentation supports authoring via markdown frontmatter or `subagent({ action: "create" })`. Recommended roles align with the monorepo's extension, governance, and release seams.
