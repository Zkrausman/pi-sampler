# Goal loop (AIDEV-343 experimental candidate; NOT installed)

A small, **off-by-default** Pi extension. Explicitly load `extensions/goal-loop/index.ts` from this package in a trusted, isolated session. `/goal-loop start <approved goal>` arms **one** conditional `agent_before_settle` continuation without an adapter (15-minute, three-turn maximum and $0.25 provider-reported cost maximum since arming; unknown usage stops closed). Additional continuations require a fresh caller-owned workstream snapshot and new successful tool evidence; no caller adapter is bundled. `/goal-loop status`, `/goal-loop wait`, `/goal-loop pause`, and `/goal-loop stop` expose or stop the in-memory state. `/goal-loop resume <fresh approved goal>` starts a **new** bounded goal ID/cursor/budget after an explicit operator command; it never resurrects a paused goal or prior work-state assertion. It pauses on error, abort, a queued/native continuation, the wait command, no new successful tool evidence after the first continuation, budget exhaustion, session tree navigation, compaction, or shutdown/reload. It never restarts Pi after exit. Load alone has no effect.

Local dependency-free unit test: `npm test` (Node 24 type stripping). Opt-in **real Pi, no-tools** RPC test: set `PI_CLI_JS` to the installed Pi `dist/cli.js`, then run `node tests/integration-rpc.mjs`; the test makes bounded provider calls, records no session and exits when settled. No pinned Pi version. No installation, global extension, order, merge or publication is part of this candidate.

## Repository boundary and open blockers before review or activation

The extension is reusable Pi infrastructure in **pi-sampler**; it must not import Squire/Gelt code, ticket IDs, private lane boards or service-specific policy. An optional caller-owned goal card or integration adapter can supply workstream state, but is not a generic safety guarantee. The prototype **does not independently verify** that a goal has remaining safe work, all approved workstreams are blocked, an operator gate is pending, or a native child is active. A model instruction and successful tool-result counter are not authority or evidence of progress. The provider-reported cost cap is an estimate, **not a billing limit**, and audit does not persist across process exit. Therefore do not use this prototype to orchestrate production work or claim AIDEV-343 acceptance. The generic event contract and limitations are in [WORKSTATE-CONTRACT.md](WORKSTATE-CONTRACT.md). The typed validator and event listener exist, but **no caller workstream adapter is implemented or reviewed**: an arbitrary same-process emitter is not a trusted source. Test adapter identity, interruption, blocked/native event states and actual Pi lifecycle in an isolated no-mutation-tools session before activation. The owner conditionally approved installation **when ready**; that does not make this unreviewed candidate ready or permit installing it now. No static Pi/extension version pinning.
