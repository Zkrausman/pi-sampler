# Security policy

## Supported versions

The current `main` branch and released packages are the supported code lines for security reports.

## Reporting a vulnerability

Do **not** open a public issue for a suspected vulnerability or include a
credential, access token, session archive, or customer data in a report.

Use [GitHub private vulnerability reporting](https://github.com/Zkrausman/pi-sampler/security/advisories/new) for this repository. Include a minimal reproduction, the affected version or commit, impact, and any mitigation you have identified.

Use the private reporting channel so the report is not exposed in a public issue or pull request. Include only the information needed to reproduce and assess the issue; do not include credentials, access tokens, session archives, or customer data.
